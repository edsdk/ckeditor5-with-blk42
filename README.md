CKEditor 5 with Blk42 build
==================================

This repository contains a build for CKEditor 5 with all the features needed for creating content block by block. This is done by including a [Blk42](https://blk42.com) as a plugin in the build.

Blk42 is a plugin for CKEditor 5 that enables full support of Tailwind 4/Bootstrap 5 with their grid systems, that lets you to add or modify column structure, save and re-use custom blocks.

Blk42 is a part of N1ED for CKEditor 5, the [`@edsdk/n1ed-ckeditor5`](https://www.npmjs.com/package/@edsdk/n1ed-ckeditor5) plugin, and this build carries the whole plugin, set up for Blk42: with a Blk42 API key it runs the blocks. Whatever your key gets later in the Dashboard (the Flmngr file manager and the Image42 image editor, formerly ImgPen, come with [N1ED](https://n1ed.com)) comes on in this same build, its buttons included, with no rebuild.

## Install

See [the installation guide](https://blk42.com/docs/install/ckeditor-5) describing using this build.
